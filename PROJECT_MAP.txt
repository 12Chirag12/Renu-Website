18. API ROUTES (Enquiry Form Backend)
================================================================================

FILE: app/api/enquiry/route.ts (63 lines)
ENDPOINT: POST /api/enquiry

FLOW:
  1. Rate limiting: Max 5 requests per IP per minute (Line 15)
  2. Honeypot check: Rejects if "website" field is filled (Line 28)
  3. Validates: fullName, companyName, email, phone, location, enquiryType, interest, message (min 20 chars), consent
  4. Sends to webhook URL from environment variable ENQUIRY_WEBHOOK_URL
  5. Returns success or error JSON

▶ TO CONFIGURE FORM DELIVERY:
  Set environment variable: ENQUIRY_WEBHOOK_URL=<your-webhook-url>
  Without it, form shows "Online enquiry delivery is awaiting company configuration"

▶ TO CHANGE RATE LIMIT:
  Line 15 → currently "attempts.length >= 5" (5 per minute)
